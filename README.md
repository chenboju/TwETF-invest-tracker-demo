# TwETF Invest Tracker 示範網站

這是 **TwETF Invest Tracker**（台股／ETF 本機投資紀錄與分析工具）的示範網站：

**https://chenboju.github.io/TwETF-invest-tracker-demo/**

- **全部是程式產生的假資料**：ETF（台幣 `DM01`～`DM08`、美元 `USDM1`／`USDM2`）、行情、配息、交易、投資組合都是假的，不是真實資料，也不是投資建議。
- 個人交易只能瀏覽，不能新增或修改；投入模擬可在瀏覽器用假行情自訂台美策略。沒有後端，行情是事先產生好的靜態檔。
- 內容只有建置好的網站，沒有原始碼。

可以看的畫面：整體損益與走勢、資產配置、損益來源、股息儀表、各檔 Dashboard（買入批次、配息與填息分析）、ETF 漲幅比較（上市後、買入後，含息與只看配息）、交易與股息紀錄。

投入模擬支援單筆、每月定期定額、兩邊多檔配置與固定情境匯率，不代表真實投資績效。
